# VIERNULVIER Archive – Project Wiki

## Overview

This project implements an archive website for Kunstencentrum VIERNULVIER.  
It is designed as a standalone archival system next to the existing marketing website.

The system consists of:

- Django backend
- Django REST Framework API
- PostgreSQL database
- React + TypeScript frontend
- Dockerized deployment
- Role-based authentication
- Import pipeline for external data sources
